Nythera — Mobile Music Player

Nythera is a lightweight, full-featured mobile music player built with React Native. It focuses on fast local music browsing and reliable background playback while exposing common user features in a modern, touch-friendly interface.

Key features

- Library scanning and playlists: import and organize local audio into playlists and folders.
- Queue-based playback: build and reorder a play queue, skip forward/back and jump between items.
- Background playback & notifications: persistent playback with lock-screen and notification controls.
- Equalizer (Android): per-band equalizer and bass boost exposed from the app UI (Android native implementation).
- Playback controls: play/pause, seek, jump forward/back, repeat and shuffle modes.
- Mini player & Now Playing: compact controls while browsing plus a full Now Playing screen with metadata.
- Downloads & offline support: manage downloaded audio for offline listening.
- Favorites & history: mark favorites and view recently played tracks.
- Output selection: choose available audio outputs where supported.

Purpose

Nythera is designed for people who prefer an app focused on local audio playback rather than streaming — it aims to be fast, privacy-friendly, and extensible for adding audio features like effects and advanced playback controls.
